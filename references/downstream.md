# Donor-level inference and downstream analyses

Use this guide after cell identities and sample assignments are available. For an external annotated object, record the input version, expression layers, label source and QC history. A full workflow assesses each branch against the research question and the verified inputs. Run eligible branches and retain the evidence for each decision in the analysis index. See [Programs and models](models.md) for expression-program discovery, reference mapping and virtual perturbation.

## Define the contrast and analysis units

- Specify target and reference groups, tissue or site, cell type, and whether the question concerns abundance, expression within a type, or variation within a lineage. Define the direction before reviewing outcomes. Use stable contrast and cell-type identifiers in paths. Below, `<P>` denotes the cohort and contrast, and `<CT>` the cell type.
- Resolve each `cell_id` to its capture, sample, independent biological unit, condition, batch and cell type. Identify pooled donors, technical replicates and repeated collections. Aggregate technical replicates from the same sample only after checking that the cell libraries are disjoint. Retain the site, time and treatment of repeated observations. For demultiplexed pools, verify individual assignments. Otherwise, retain the pool as the observed sample and document which donor comparisons it supports.
- Save `clean_data/<P>_sample_info.csv` and `results/design/<P>_coverage.csv`. Include expected samples, available pre-QC and post-QC counts, total counts and target-cell counts, distinct donors by group, complete pairs and missing covariates. Prespecify a minimum coverage rule suitable for this assay and estimand. Show exclusions with reasons for each cell type. Calculate donor counts again for the fitted model.
- Check group-by-batch and group-by-site tables, design-matrix rank, residual degrees of freedom and within-pair overlap. Multiple cells from one donor increase expression coverage. Inference across subjects uses independent donors or a model accounting for repeated observations. With complete condition–batch confounding, provide the sample summaries and identify the contrast that remains unidentifiable. Continue with other estimable questions.

## Abundance and composition

1. Define the numerator, denominator and sampling frame. Examples include microglia among all QC-passing cortical nuclei, or a state among QC-passing microglia. Record how enrichment, doublets and uncertain labels affect each denominator. For an observed eligible sample, record zero for an absent type. A missing sample or a zero denominator yields a missing proportion. Report absolute density only with suitable measurements of tissue amount or cell recovery.
2. Build the complete sample-by-type count table, including observed zeros. Save counts and proportions in `results/composition/`. Plot donor points with denominators and connect paired observations. Model type counts and denominators jointly where appropriate, for example with a beta-binomial model, a compositional method with a documented reference, or a mixed model for repeated samples. Check dispersion, sparse categories, donor imbalance and the stability of the chosen reference.
3. Report the effect in interpretable units, such as an adjusted percentage-point difference, or an odds ratio with the reference stated. Include uncertainty, number of independent units, multiplicity family and adjusted P values. For continuous state abundance, an additional miloR analysis requires a biologically comparable graph and neighborhood counts per sample. Save the neighborhood definitions, sample coverage, effect estimates and spatial FDR. Keep it distinct from abundance by named cell type.

## Expression within cell types

1. With unnormalized gene counts, sum counts within each biological sample, condition and cell type. Preserve gene IDs and match each pseudobulk column to exactly one sample-table row. Check that library sums agree with the selected cells. A sample with zero cells of that type has no expression library for that type.
2. Filter low-expression genes within each tested type, normalize pseudobulk libraries and inspect library sizes, sample PCA or MDS, relevant covariates and influential donors. Fit a design-compatible count model such as edgeR quasi-likelihood or DESeq2. A complete two-condition paired design can use `~ donor + condition`. For repeated sites or times, define the exact contrast and account for within-donor dependence. Comparing response magnitudes across cell types requires a cell-type-by-condition interaction or equivalent joint test.
3. In `results/DEG/`, save the count matrix, model design, donor inclusion table, the full tested table and a significant subset with headers even when empty. Include stable ID, gene symbol, target-minus-reference log2 fold change, test statistic, raw P value, FDR and group donor counts. Give effect uncertainty for designated outcomes and name the estimator if the interval comes from a different fit. Record filtering and multiplicity rules. For targeted panels, distinguish absent features, filtered features and tested genes. Show donor-level expression for the prespecified targets.
4. With normalized RNA only, verify the transformation, summarize expression or scores on the documented scale per donor and type, and report the coverage. An unreplicated group can support a descriptive atlas. Check the original release for an aligned count layer if a count-based result is requested.

## Functional enrichment and expression scores

Treat each method as a separate branch because the inputs, tested hypotheses and outputs differ.

| Analysis | Execution | Evidence to save |
|---|---|---|
| GO, KEGG or other overrepresentation analysis | Use a versioned, species-matched collection. Test upregulated and downregulated foregrounds separately against all genes actually tested and mappable in that contrast. Resolve duplicate IDs and report mapping loss. If a foreground is empty, record its size and retain the valid ranked analysis. | In `results/Enrich/`, save foreground and background IDs, term ID and name, overlap counts and genes, effect or enrichment ratio, P value and FDR over the stated family. |
| Preranked GSEA | Rank all tested, mapped genes by a finite directional statistic. For a one-degree-of-freedom contrast, examples are a Wald statistic or `sign(log2FC) * sqrt(F)` for an edgeR QL F-test. Resolve ties and duplicate identifiers. Apply stated gene-set overlap and size limits. | In `results/GSEA/`, save the signed ranking, collection version, exact memberships or a versioned reference, matched set sizes, NES, P value, FDR and leading-edge genes. Record the null model. For closely coexpressed sets, a correlation-aware test can assess robustness. |
| Prespecified gene or regulon score | Document membership, direction, measurable fraction and scoring scale. Calculate a within-cell score with an appropriate method such as UCell, or define a score on donor pseudobulk. Use consistent membership for external confirmation or repeat the comparison using the common measurable genes. | Save scores, coverage, donor-level estimates and plots. Compare groups with the independent unit and covariates used in the design. Report when low detection limits interpretation. |

A list of enriched terms from a prior publication can provide context. The executed branch needs the current contrast's inputs, test results and database version.

## Pseudotime and state trajectories

Cross-sectional profiles can support an exploratory ordering of states within a lineage. Define the biological transition, population and independent sampling units. Identify what observation could orient the trajectory, such as measured collection time, a documented precursor identity or an independently defined homeostatic program. Record whether this orientation is observed or hypothesized.

1. **Inspect a lineage-specific manifold.** Subset related cells and recompute informative features, normalized expression, PCs or diffusion coordinates, and a neighborhood graph. Check continuity, disconnected components, multi-donor support and segregation by capture, condition, depth, stress or cell cycle. Inspect the uncorrected representation when using batch correction. When testing a target program along the ordering, exclude its defining genes from the root criterion and check an embedding that also excludes those genes.
2. **Fit and orient the ordering.** For cluster-supported endpoints use Slingshot principal curves or a comparable method. For a connected continuum use diffusion pseudotime or a documented graph-distance method. Choose the root before examining target-gene trends and record the biological evidence, exact root cells or cluster, endpoint constraints, graph and parameters. Fit disconnected components separately when identifiable. If a meaningful orientation cannot be supported, retain an unoriented state map, graph neighborhoods or descriptive gradients and record the limitation. A bifurcation requires support from cells and multiple independent donors along each proposed arm.
3. **Check stability.** Repeat with at least one biologically plausible alternative root when available. Compare rank correlation on the same cells, shared branch assignments and endpoint support. Assess sensitivity to graph or cluster resolution, donor-balanced sampling and omission of influential donors. Report how strongly ordering tracks depth, batch and donor. Unstable ordering can be reported as an exploratory sensitivity result.
4. **Relate the ordering to the question.** For prespecified genes or programs, show curves with donor coverage along each branch or bin. For formal inference, use donor-aware smooths, donor-by-bin aggregates with a repeated-measures model, or paired donor-level summaries. Report supported regions of the curve, contributing donors, uncertainty and FDR when testing multiple genes. If the question concerns group occupancy along pseudotime, compare donor distributions or bin counts with their denominators. Distinguish an inferred state ordering from chronological progression or ancestry.
5. Save `results/trajectory/` with cell IDs, independent unit, component, root definition, pseudotime, branch weights or assignments where supported, method, input features, graph or fitted curves, donor coverage, root-sensitivity table, fitted trends and figures colored by donor, condition and state. Index ordering, branch-specific tests and donor-level group comparisons separately when their feasibility differs.

## Other branches and prerequisites

| Branch | How to decide and execute | Output |
|---|---|---|
| RNA velocity | Verify raw spliced and unspliced layers with matching features and cells, sufficient signal and a plausible kinetic model. Inspect phase portraits, model fits and neighborhood consistency. A count matrix or pseudotime coordinate alone cannot supply these measurements. | `results/velocity/` with model diagnostics, per-cell estimates, uncertainty or confidence and a field visualization. |
| Lineage tracing | Require measured heritable labels or time-resolved experimental tracking, verified cell assignment and suitable coverage. Reconstruct clone membership and supported lineage relationships, stating label collisions or ambiguous ancestry. | `results/lineage/` with clone assignment, tree or lineage relationships and support. |
| Gene regulatory networks | Check transcription-factor and target coverage, species-matched motif or regulatory resources, and replication. For SCENIC, infer coexpression, prune candidate targets with motifs and score regulons. A curated regulon-activity analysis answers a separate question and needs a versioned signed network. | `results/GRN/` with network or regulon definitions, evidence, activity summaries by donor and uncertainty for comparisons. |
| Cell–cell communication | Verify matched senders and receivers in the same biological samples, expression coverage for all required complex subunits and an appropriate species-specific ligand–receptor resource. Run inference by sample where feasible, assess cell-count sensitivity and compare donor-level signals across groups. | `results/communication/` with eligible pairs, sample coverage, tested ligand–receptor interactions, effect estimates and uncertainty. RNA evidence nominates candidate interactions. |
| Measured perturbation | Verify observed treatment or perturbation assignments, matched controls and independent replicates. Analyze within-type expression and abundance separately. Include assignment uncertainty and possible batch confounding. | `results/perturbation/` with design, coverage and estimated treatment effects. Assess in-silico perturbation independently using [Programs and models](models.md). |
| Bulk deconvolution | Verify that an actual bulk cohort, reference expression matrix, gene mapping and matching tissue identities are available. Assess reference coverage, platform compatibility and sensitivity to reference donors and similar cell types. | `results/deconvolution/` with proportions, reference diagnostics and available independent benchmarks. |

## Evidence, reporting and replication

Maintain `results/analysis_index.csv` with the canonical columns `stage_id,branch,contrast,cell_type,required_inputs,evidence,status,output_paths`. Use the stage identifiers and status meanings in the main workflow guide. Keep one row per separately decidable branch, contrast and cell type. For example, a successful pseudobulk fit and an untestable trajectory need separate rows. Multiple paths in `output_paths` are separated by semicolons and relative to the project root. In `evidence`, record the files or resource versions inspected, the test or diagnostic performed, effective independent units and any specific limitation. Optional columns may hold structured donor counts, parameter versions or replication roles. Verify that each listed output opens and corresponds to its row.

Save scripts, parameters, seeds and package versions. Retain empty tested-result tables with column definitions. Reference effect estimates, uncertainty, donor coverage and key sensitivity results in `report/<P>_single_cell_analysis_report.md`. Before external validation, identify cohort or donor overlap and fix the target genes, programs, cell labels, contrast direction and replication criterion. Label leave-one-donor-out checks, held-out donors, separate-cohort replication and model predictions according to their actual designs.
